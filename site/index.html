Questions

Is it free?

Yes. is free and there is no account to create. If you choose Claude with your own API key, Anthropic bills your API account directly; the local model costs nothing.

Is it open source?

Yes. The source is published under the GNU GPL v3 (or later): you can read it, build it yourself and change it, and versions others share stay open too.

Which operating systems does it run on?

Windows 10 and 11, and macOS on Apple silicon and Intel Macs. The installers are not code-signed yet: Windows may say "Windows protected your PC" (More info, then Run anyway), and a Mac asks you once to allow it in System Settings, Privacy & Security. The Windows app updates itself. Linux is not supported yet.

What comes over from Arc and my old browser?

From Arc: your spaces with their colours and icons, pinned tabs and folders. From Chrome, Edge, Brave, Firefox and Safari: bookmarks and history. Passwords come in from the CSV file those browsers and password managers export. Every import only reads; nothing in the other browser changes.

Do Chrome extensions work?

Yes, Manifest V3 extensions from the Chrome Web Store install with Add to Chrome and update on their own. A few Chrome-only features may not work yet.

Can I keep a vertical sidebar like Arc?

Yes. Settings › General › Layout switches between the top bar with tabs and the classic sidebar, any time.

Does it sync between devices?

No. There is no account and no sync server. Your spaces, tabs and settings live on your computer.

Do I have to use AI?

No. AI is off until you turn it on in Settings, and you choose which engine runs each feature.
